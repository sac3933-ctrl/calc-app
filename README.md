# 공학계산기 연습장 (fx-570ES PLUS)

Casio fx-570ES PLUS 2nd Edition의 키 순서를 「센서 및 응용」 기출·숙제 계산으로 익히는 웹앱입니다.

- 따라하기 → 힌트만 → 실전 3단계 연습, STAT(A+BX) 회귀, 사고 복구 시나리오, 25분 모의시험
- 홈 화면에 추가하면 앱처럼 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다
- 진도는 각 기기의 브라우저에만 저장됩니다

실물 계산기 동작을 따라 만든 연습기라 √ 꼴 표시, MATRIX·방정식 모드 등 일부 기능은 단순화되어 있습니다.
